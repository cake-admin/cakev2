# cake&

Welcome to **cake&** — Lenovo's design system. This Storybook is the catalog:
every color, type size, and component, shown live so you can click around
before you use it in a file.

You do **not** need to be a developer to start a prototype. The steps below
download a ready-made project (the **devkit**) onto your computer. A coding
agent such as Cursor can then build screens from cake& components for you.

## Use cake& (the devkit)

You need [Node.js](https://nodejs.org/) installed (the LTS version is fine).
That gives you the `npm` command. Then open a terminal (Terminal on Mac,
PowerShell on Windows) and follow one of the two paths.

### Path A — I want a new prototype (recommended)

This copies a small starter project onto your machine. It is **not** a clone of
the whole design-system repo. No GitHub password or token is required.

**1.** Download the starter into a folder named `my-prototype` (you can pick
any name):

```bash
npx degit cake-admin/cakev2/starter my-prototype
```

The first time, your computer may ask “ok to proceed?” — type `y` and press
Enter. `npx` means “run this helper once”; `degit` means “copy these files,
without git history.”

If that command fails, this does the same thing:

```bash
npx giget@latest gh:cake-admin/cakev2/starter my-prototype
```

**2.** Move into that folder:

```bash
cd my-prototype
```

**3.** Install the pieces the project needs (this can take a minute):

```bash
npm install
```

**4.** Start the local preview:

```bash
npm run dev
```

Your terminal will print a link, usually `http://localhost:5173`. Open it in a
browser. You should see a small cake& page with a light/dark toggle.

**5.** Open the `my-prototype` folder in Cursor (or another coding agent) and
ask for what you want — for example, *“build a settings page with tabs and a
save button, using cake& components.”*

To pull a newer cake& version later, from that same folder run
`npm run cake:update`.

### Path B — I already have an app

If an engineer already has a React project, cake& installs from a **release
file** (a `.tgz` on GitHub). Still no login:

1. Open the [latest release](https://github.com/cake-admin/cakev2/releases/latest)
   and copy the `cake-admin-cakeand-….tgz` download link.
2. In the project folder, install that file, then the five libraries cake&
   expects to share with the app:

```bash
npm install https://github.com/cake-admin/cakev2/releases/download/vX.Y.Z/cake-admin-cakeand-X.Y.Z.tgz
npm install react react-dom styled-components radix-ui lucide-react
```

Replace `vX.Y.Z` with the version you see on the release page (for example
`v1.0.0`).

3. Wrap the app **once** in `CakeProvider` (the starter already does this):

```tsx
import { CakeProvider, Card, HeroCard, Button } from '@cake-admin/cakeand';

<CakeProvider mode="light.a">
  <Card>
    <HeroCard title="Hello" actions={<Button size="lg">Get started</Button>} />
  </Card>
</CakeProvider>;
```

The extra wiring (theme on the page, fonts, a shared copy of
`styled-components`) is already done in the starter. If you are adding cake& to
an existing app, follow the numbered checklist on
[Getting Started](?path=/docs/cake-maintenance-getting-started--docs).

### If something goes wrong

| What you see | What to try |
| --- | --- |
| The page has no color / looks “unstyled” | You skipped `npm install`, or the cake& stylesheet did not load. In the starter it is imported in `src/main.tsx`. |
| `npx` or `npm` is “not recognized” | Node.js is not installed, or the terminal was open before you installed it. Close the terminal and open a new one. |
| Odd npm errors on Windows | Do not put the project in a folder whose name contains `&`. Rename the folder. |
| `npm error EINTEGRITY` | Delete `package-lock.json` and run `npm install` (starter: `npm run cake:update`) again. |

More detail, including “add cake& to an app we already have,” is on
[Getting Started](?path=/docs/cake-maintenance-getting-started--docs).

## What this Storybook is for

- **Foundations** — color, type, space, elevation.
- **Components** / **Elements** — click a component, change controls, copy the
  usage snippet. Start with Button if you want a simple example.
- **Cake& Maintenance** — for the design-system team (how we build and ship).
  Designers building prototypes can skip it.

Use the **Theme** toolbar at the top to switch **Light A**, **Dark A**, and
**Windows HCT**. Every example on the page re-themes.

## Running this Storybook on your machine (cake& team)

If you cloned the full `cakev2` repo to work on the system itself:

```bash
npm run storybook              # http://localhost:6006
npm run build-storybook        # static build
```

The folder path contains `&`, which breaks some Windows shortcuts. Use
`npm run storybook` rather than `npx storybook`.
